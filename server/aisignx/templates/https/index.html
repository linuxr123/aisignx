HTTPS with nginx

System

The web page and the screens should be reached over HTTPS: sign-in, pairing and the commands sent to the screens then cannot be read or changed on the network. AiSignX itself speaks plain HTTP; nginx sits in front, holds the certificate and passes the traffic on. Set it up with scripts\setup-nginx.ps1 (Windows) or scripts/setup-nginx.sh (Linux); this page makes and checks the certificate and gives you the configuration. See docs/https.md.
